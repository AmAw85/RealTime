# fwmon — مراقبة الشبكة حسب التطبيق

[Français](README.md) · [English](README.en.md) · **العربية**

أداة صغيرة تعمل في الطرفية، على غرار أجهزة جدار الحماية (Fortinet / FortiView): تعرض في
الوقت الفعلي **ما يفعله كل تطبيق على الشبكة** — الجلسات، واتجاه حركة البيانات
(IN / OUT / LOCAL)، ومعدّل النقل، والمواقع التي يتصل بها، والمنافذ المُصغية (listening).

> واجهة البرنامج نفسها باللغة الفرنسية (التسميات والتنبيهات والتوصيات). هذا الملف يوثّقها
> بالعربية.

## ما الذي يفعله

- **التطبيقات** (Applications): سطر لكل تطبيق (مجمَّع حسب اسم العملية)، مع عدد الجلسات،
  والبایتات المُرسَلة / المُستلَمة، وخلاصة لنشاطه (الخدمة الرئيسية + المواقع التي يتصل بها).
- **الاتصالات** (Connexions): كل جلسات TCP/UDP، مع PID، والاتجاه (IN / OUT / LOCAL)،
  والمضيف البعيد، والخدمة، والحالة، والمستخدم المالك، والنشاط («actif» أو الزمن المنقضي منذ
  آخر بايت متبادل)، و**مستوى الخطورة**. تُعتَّم الأسطر الخاملة لأكثر من دقيقة.
- **التنبيهات** (Alertes): مؤشرات مكتشفة، مجمَّعة حسب القاعدة / التطبيق / السبب، مع المستوى،
  وعدد الجلسات المعنية، وتوصية.
- **النطاقات** (Domaines): المواقع التي جرى الاتصال بها (DNS سلبي + TLS SNI + بحث عكسي)،
  والتطبيقات المعنية، وحركة البيانات المتبادلة.
- **الوارد** (Entrant): الاتصالات الواردة والمنافذ المُصغية.
- **Enter / d**: عرض التفاصيل (جلسات تطبيق مع المستخدم والملف التنفيذي؛ ثم بطاقة كاملة
  للجلسة: PID، المستخدم، الملف التنفيذي، سطر الأوامر الكامل، الواجهة، RTT، العمر، آخر نشاط،
  البايتات، UID، والتنبيهات مع توصيتها).

## التنبيهات — مؤشرات لا أدلّة

كل تنبيه يعرض مستوى (**faible**، **moyen**، **élevé** — ضعيف، متوسط، مرتفع)، والتطبيق
والاتصال المعنيين، والسبب الدقيق، وتوصية. القواعد بسيطة وقابلة للتفسير، وتُحسَب محليًّا من
بيانات سبق جمعها:

| القاعدة | المستوى | سبب التشغيل |
|---|---|---|
| عملية غير معروفة | ضعيف | مقبس بدون PID (النواة، أو جمع بدون صلاحيات) |
| ملف تنفيذي غير متاح | ضعيف | العملية حيّة لكن مسار ملفها التنفيذي غير قابل للقراءة |
| ملف تنفيذي خارج المسارات النظامية | متوسط | ملف ثنائي خارج `/usr`، `/opt`، `/snap`، `/var/lib/flatpak`… |
| ملف تنفيذي مشبوه | مرتفع | ملف ثنائي انطلق من `/tmp`، `/var/tmp`، `/dev/shm`، `/run/user` |
| خدمة حسّاسة | متوسط | حركة صادرة تغادر الشبكة المحلية نحو FTP، TELNET، SMB، RDP، VNC، قواعد البيانات… |
| منفذ غير معتاد | ضعيف | منفذ بعيد بلا خدمة معروفة (اتصال قائم) |
| وارد من الشبكة الخارجية | متوسط | اتصال وارد قائم من خارج الشبكة المحلية |
| عدد الاتصالات | متوسط / مرتفع | أكثر من 120 / 300 اتصال متزامن لتطبيق واحد |
| محاولات متكرّرة | متوسط / مرتفع | 8 اتصالات (4 بحالة SYN) إلى الوجهة نفسها خلال 60 ثانية |

النطاق غير المعروف **لا** يُعدّ مشبوهًا بحد ذاته: عند غياب اسم محلول تُعرض عنوان IP، وغياب
الاسم ليس تنبيهًا. العتبات إرشادية لا نهائية — التنبيه يستدعي التحقق (التوصيات تعطي الأمر
الواجب تنفيذه). **fwmon لا يوقف أي عملية ولا يحجب أي اتصال**، ولا يرسل أي بيانات إلى الخارج.

## كيف يعمل

- تعمل الواجهة **بمستخدم عادي**.
- يُشغَّل **جامع واحد بصلاحيات root** عند الإطلاق عبر `sudox` (أو `sudo -n` كبديل). يقرأ
  `ss -tunapie`، و`/proc/<pid>/cmdline`، و`/proc/<pid>/exe`، و`ip addr`، ويلتقط بشكل سلبي
  DNS (المنفذ 53) وTLS ClientHello (SNI، المنفذ 443) عبر مرشّح BPF داخل النواة. بدون
  صلاحيات يبدأ البرنامج مع ذلك في وضع محدود، ويُبلّغ بوضوح عن المعلومات الناقصة بدل اختلاق
  بيانات.
- تُحسَب **التنبيهات** في الواجهة، في الذاكرة، من ذلك التدفّق؛ بلا أي نداء خارجي، وبلا ملف،
  وبلا قاعدة بيانات.
- يكتب الجامع **NDJSON على خرجه القياسي**، وتعرضه الواجهة.
- **قراءة فقط**: لا يُعدَّل أي حزمة ولا تُسقَط ولا تُحقَن. لا تُمسّ أي قاعدة جدار حماية،
  ولا تُوقَف أي عملية، ولا يُحجَب أي اتصال.
- **لا شيء يغادر الجهاز**: كل المعالجة (بما فيها التنبيهات) محلية، ولا شيء يُكتب على القرص —
  بلا سجلّ تاريخي، وبلا قاعدة بيانات.

## المتطلبات

- Linux، وPython 3.10+ (مُختبَر على Ubuntu 26.04 / Python 3.14)، و`ss` (حزمة `iproute2`).
- `sudo` للجمع بصلاحيات. يستخدم fwmon أداة `sudox` (`~/.local/bin/sudox`، askpass غير
  تفاعلي) إن وُجدت، وإلا `sudo -n` إذا كانت الجلسة مفتوحة أصلًا (`sudo -v`). بدون صلاحيات
  يبدأ البرنامج في وضع محدود ويصرّح بذلك.
- `screen` للاختصارات و`fwmonctl` (اختياري).
- طرفية UTF-8 (تُستخدم الأسهم ↑ ↓ والحروف المشكَّلة).

## التثبيت

```sh
cd ~/fwmon
./install.sh              # يُنشئ ~/.local/bin/fwmon (رابط رمزي)
```

ثم:

```sh
fwmon
```

أو مباشرة:

```sh

```

## اختصارات سطح المكتب (القائمة + سطح المكتب)

```sh
./shortcuts.sh
```

يثبّت ثلاثة اختصارات في قائمة **التطبيقات** وعلى **سطح المكتب**:

| الاختصار | الأثر |
|---|---|
| **fwmon — Lancer la surveillance** | يشغّل fwmon في نافذة طرفية |
| **fwmon — Afficher** | يعيد فتح النافذة (يبقى البرنامج يعمل في الخلفية) |
| **fwmon — Fermer** | يوقف البرنامج **وجامعه** بصلاحيات root |

الأوامر نفسها من سطر الأوامر:

```sh
fwmonctl start | show | stop | status      # تشغيل | إظهار | إيقاف | الحالة
```

يعمل fwmon في جلسة `screen` منفصلة: إغلاق النافذة لا يوقفه، و«Afficher» يعيد فتحها،
و«Fermer» يوقفه بنظافة (يُوقَف الجامع ذو صلاحيات root في كل الحالات، بما في ذلك عند
`SIGTERM`/`SIGHUP`).

لإزالة الاختصارات:

```sh
rm ~/.local/share/applications/fwmon-*.desktop ~/Desktop/fwmon-*.desktop
```

## قيود معروفة

- **Chrome / Firefox** يستخدمان غالبًا DNS-over-HTTPS، وأكثر فأكثر ECH (Encrypted Client
  Hello): عندئذ لا يظهر اسم الموقع ويُعرض عنوان IP (مع اسم PTR إن وُجد).
- **QUIC (UDP 443)** يشفّر SNI أيضًا؛ ولا تُفكّ إلا جلسات TCP/TLS.
- **عدّادات البايتات** تأتي من `ss`: وهي متاحة لـ TCP فقط (يعرض UDP شرطة `-`).
- المقابس بلا عملية مرئية (Docker NAT، النواة) تظهر باسم `(noyau)` (النواة) أو باسم مالك
  UID، مع تنبيه «عملية غير معروفة».
- مسار الملف التنفيذي يتطلب قراءة `/proc/<pid>/exe`: بدون صلاحيات يُعرض
  «indisponible» (غير متاح). تُتبَّع معرّفات PID مع وقت بدئها في النواة، ما يمنع نسبة اتصال
  إلى PID أُعيد استخدامه.
- التنبيهات **استدلالية**: الأخطاء الإيجابية الكاذبة ممكنة (المتصفحات، P2P، عملاء المزامنة)،
  وبعض الحالات غير قابلة للكشف (DoH/ECH/QUIC، حركة مشفّرة، ملف نظام مخترَق).
- السجلّ في الذاكرة فقط: إغلاق الأداة يمسحه.

## استكشاف الأخطاء

- `[utilisateur]` بدل `[root]` في الترويسة: لم يُعثر على `sudox` أو فشل. تحقّق من
  `sudox true`، أو افتح sudo أولًا بـ `sudo -v`.
- `ERREUR : …` في التذييل: توقّف الجامع؛ اضغط `r` لإعادة تشغيله.
- لا يظهر أي نطاق رغم وجود حركة: تعذّر تثبيت مرشّح BPF (نادر)؛ أعد التشغيل بـ `r`. تحقّق
  أيضًا من أن الحركة ليست QUIC/ECH.
